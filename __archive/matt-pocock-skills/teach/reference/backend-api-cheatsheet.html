Backend / API cheat sheet

How the screen talks to the Brain: a request goes in, a response comes back. Everything here is for reading and reviewing endpoints — not writing them.

Status codes

2xxgood — it worked
4xxyour fault (bad request, not allowed, not found)
5xxthe server's fault (a bug)

400 bad · 401/403 not allowed · 404 not found · 500 server bug

JSON — the message format

→ Request

{ "sku_id": "NK-AM90-WHT-8",
  "qty": 1,
  "store": "Store-7" }

← Response

{ "status": "ok",
  "bill_no": "BILL#902",
  "on_hand": 4 }

JSON is just label: value text both sides understand.

🧭 Reviewer's lens for any write endpoint (POST/PUT/DELETE):  (1) Does it check who is allowed?  (2) Does it validate the input (reject rubbish → 4xx)?  (3) Is the database write scoped (the WHERE)?  (4) Does it return a clear status code?
