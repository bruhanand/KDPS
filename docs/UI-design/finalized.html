Direction 01 · Quiet Color

KDPS design kit

Design posture

Fashion warmth meets operational precision. White is the working surface; frost gives navigation depth; pastels create recognizable neighborhoods without weakening data legibility.

Memorable thing

“This ERP feels calm, crafted, and fast — not like accounting software.”

Color roles

Pastels are containers, not status colors. Status keeps a separate, higher-contrast semantic palette.

Material rules

  • Use frosted glass for the sidebar, popovers, drawers, and command surfaces. Keep tables, forms, and reading surfaces opaque.
  • Never stack translucent panes edge-to-edge. A clear border or solid layer must separate them.
  • Offer reduced-transparency fallbacks and preserve strong text and focus contrast on every material.
  • Use compact density for mouse-and-keyboard tables; keep comfortable 44px touch targets on mobile.
  • Use pastel container roles for category and grouping; use semantic colors only for status and risk.
