How the project is organized now. Two big buckets: docs/my-understanding/ = the work Anand produces (system design, requirement write-ups, the as-is workflow) and docs/data-from-kdps/ = raw material received from the client (reference files, Q&A answers, bank statements, monthly-report data, store analysis). →House rules — where new things go

New design discussion? New numbered folder under docs/my-understanding/system-design/ (e.g. 06-tally-sync/).
New meeting? docs/meetings/YYYY-MM-DD-topic/ with audio + transcript + minutes.
New month's report work? Its month folder under docs/data-from-kdps/monthly-reports-april-may-2026/ (or the current monthly-reports folder), with a data/ subfolder for raw store files.
New client deliverable? docs/04-client-docs/. When superseded, move the old one to docs/__archive/.
Something stale? Never delete — move it into docs/__archive/ so the active folders stay clean.
