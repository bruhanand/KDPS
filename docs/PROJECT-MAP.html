→House rules — where new things go

New design discussion? New numbered folder under my-understanding/system-design/ (e.g. 06-tally-sync/).
New meeting? meetings/YYYY-MM-DD-topic/ with audio + transcript + minutes.
New month's report work? Its month folder under data-from-kdps/monthly-reports-april-may-2026/ (or the current monthly-reports folder), with a data/ subfolder for raw store files.
New client deliverable? 04-client-docs/. When superseded, move the old one to __archive/.
Something stale? Never delete — move it into __archive/ so the active folders stay clean.
