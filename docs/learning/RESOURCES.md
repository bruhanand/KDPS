# KDPS Stack Learning — Resources

## Knowledge

- [The KDPS repo itself — `app/backend/` + `app/frontend/`](../../app)
  The primary text. Every lesson reads real files here. Use for: everything.
- [CONTEXT.md + `docs/my-understanding/system-design/00-system-architecture.html`](../../CONTEXT.md)
  The design of record: 12 rules, five layers, kernel contracts. Use for: P8, and the "does this obey the design?" question in every phase.
- [Pro Git, 2nd ed. — Chacon & Straub (free, official)](https://git-scm.com/book/en/v2)
  The canonical Git book. Use for: P0 lessons on `log` / `blame` / `diff`, and P7 workflow.
- [Django 5.1 official docs](https://docs.djangoproject.com/en/5.1/)
  Primary source for the framework KDPS runs. Use for: URL dispatcher & request/response (P0 L2–L3), then all of P3.
- [Django REST Framework docs](https://www.django-rest-framework.org/)
  Official DRF guide. Use for: serializers/views/permissions (P0 tracing, all of P4).
- [ripgrep user guide (BurntSushi, official)](https://github.com/BurntSushi/ripgrep/blob/master/GUIDE.md)
  Use for: P0 L4, search-as-navigation.
- [Python 3.12 official tutorial](https://docs.python.org/3.12/tutorial/)
  Primary source for P1. Use for: syntax questions from any phase.
- [PostgreSQL 16 official docs](https://www.postgresql.org/docs/16/)
  Primary source for P2 (transactions, constraints, triggers).
- [TypeScript Handbook (official)](https://www.typescriptlang.org/docs/handbook/intro.html) and [react.dev Learn](https://react.dev/learn)
  Primary sources for P5.
