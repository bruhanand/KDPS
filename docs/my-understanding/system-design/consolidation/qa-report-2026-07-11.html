KDPS Operating System · Alpha QA

Whole-app browser test of the deployed alpha

Run on 11 July 2026 against kdps-erp-web.onrender.com (Render alpha, main branch) from inside the Claude-app browser. Scope agreed with Anand: full writes (test data prefixed QA-0711) and owner pass + role spot-checks (ops1, accounts1, deo.cashier). Every claim below cites an observed value, voucher number, or API response from the session.

Verdict

PASS — the built slice works end-to-end, and the books stay balanced under load

Every wired screen loads and functions. The full business spine — booking → GRN (both against-booking and booking-less direct) → PT authoring → warehouse mapping → send to Patna → post — completed without a single error, producing correct gap-free voucher numbers at every step. The money assertion held: trial balance was ₹0 before testing (2 vouchers / 4 legs) and ₹0 after all writes (8 vouchers / 16 legs), balanced: true both times. Stock was valued at P RATE exactly as locked (4 × ₹899 = ₹3,596). Role gating held on client and server (all probes 403). Zero console errors across the entire session, including a full mobile (375px) pass.

No P0s found. 3 P1s, 4 P2s, plus coverage gaps that need a human tester (file uploads, downloads, 4 untested roles).
