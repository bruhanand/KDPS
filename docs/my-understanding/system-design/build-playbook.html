The short answer

Read this and you have it.

The design is essentially done. D1–D8 are complete; only D9 (migration & rollout) is left to design. We are not at "start coding" yet — two normal stages come first: detailed design + data model, then project setup.

Then build module by module, each as a thin slice that runs end to end (one real document → ledger → screen), starting with the simplest real path. You review every change; money code is always supervised.

You do not lock everything first. You write the spec for one feature, build it, move to the next. And the outside systems — POS, Tally, barcode — are connected later, when you reach the part that uses them, not finalised up front.

The build loop — one feature at a time

The same cycle for every slice. The spec leads; the screen is designed near the end. You hold two gates.

  1. Spec — a fresh session writes a short, self-contained spec for the feature; you approve it. Cheap to fix here.
  2. Tests first — for ledgers / GST / payments, you write or verify the expected input→output (golden-master). This is TDD — no fake implementations.
  3. Build — the AI implements until tests pass, on its own branch.
  4. Verify — automated tests green + golden-master match. Green = done; "looks done" doesn't count.
  5. Design the screen — now lay out this module's UI from the component library, and wire it in.
  6. Review — AI review in a fresh window, then you read the change. Mandatory on anything touching money.
  7. Ship — merge the branch, tick the backlog item, move to the next.
Two speeds. Money code (ledgers, payments, Tally) = supervised, you read every change. Screens, reports, scaffolding = let it run, review the result.

Chat-to-screen UI with a live canvas; DesignSync keeps components in sync with code.

One safeguard. Some of these are pre-1.0 / preview tools. Keep the method independent of any one tool — the discipline (spec → test → build → verify → review → ship; golden-master tests; money code supervised) lives in CLAUDE.md, so if a tool changes, the plan survives.
